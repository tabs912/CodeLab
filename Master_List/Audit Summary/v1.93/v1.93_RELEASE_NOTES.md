# Master List Engine v1.93 — Corrected Production Candidate

## Functional Summary

v1.93 is rebuilt from the complete v1.92 module source rather than the regressed/truncated v1.93 draft. It preserves the full Refined Data monthly synchronization, Disenrolled Exclusion extraction and 365-day visibility sweep, Master List synthesis, and Monthly Change comparison engines while applying the approved corrections recorded in `Critcal Audit Report v1.92.pdf`.

## Complete Change Log

- Replaced the formatter-prefix temporal-dead-zone initializers with static strings.
- Restored the governed grid/header/data helper population and retained complete v1.92 workflow bodies.
- Removed global `normalizePMR_`, `normalizeCompareValue_`, `normalizeToDateObject_`, and `safeSheetName_` helpers; affected workflows now use direct local string/value/date handling.
- Consolidated month prompting into one context-object contract accepting `M`, `MM`, `MM.YY`, or `MM/YY`, locked to reporting year 2026.
- Made Refined Data resolve only the exact `Refined Data` tab and made CP Due/Unlocked CP resolvers require exact prompted-month names without latest-sheet fallback.
- Made required sheet naming fail on collision instead of deleting the existing sheet.
- Restored template configuration, metadata, grid sizing, banding, general Section C widths, and operational Section F width overrides.
- Restored Dashboard Quality callbacks, fail-closed Quick Start-up dependencies, dynamic Format Dashboard Section B–H review, and template validation.
- Added persistent timing enable/disable state and made timing logging honor it.
- Changed the rebuild-default workflow to save the complete Format Dashboard value/background matrix as JSON and added the companion restore menu workflow.
- Integrated `INDEX_RESTORE_WEB_APP_URL` into the Index missing-local-sheet message.
- Required a configured archive workbook and explicit successful archive verification before local source deletion.
- Removed the hard-coded archive workbook fallback from production archive paths.
- Added document-lock protection with guaranteed release for timed data/destructive workflows.
- Added strict governed-header validation before monthly output generation and excluded the imported header row from output data.
- Updated source, dashboard, and template metadata to v1.93.
- Restored v1.8 process parity for Monthly Start/Update orchestration, individual report formatters, smoke/full quality checks, compatibility entry points, and the archive restore web handler.

## Dependency Impact

- Uses existing Apps Script services already covered by the project manifest: `SpreadsheetApp`, `PropertiesService`, `Utilities`, `Session`, and `LockService` through the script runtime scope.
- Requires document properties `RFF_ARCHIVE_SPREADSHEET_ID` for archive workflows. Optional properties are `RFF_TIMING_ENABLED`, `RFF_ENABLE_AUTO_ARCHIVE_RAW_DATA`, `RFF_FORMAT_DASHBOARD_DEFAULT_JSON`, and `INDEX_RESTORE_WEB_APP_URL`.
- Requires the governed Format Dashboard, Dashboard Quality Report, base template, operational templates, and source-sheet headers before their dependent workflows run.

## Performance Impact

- Data/header mapping remains batched and in memory.
- Document locks serialize timed production workflows, trading limited wait time for sheet-integrity protection.
- Dashboard backup serializes the used value/background matrix once per explicit save.
- Archive verification adds destination dimension checks before deletion.
- Dynamic Dashboard Quality validation scans the Format Dashboard matrix once per start-up audit.

## Known Runtime-Dependent Items

- Live spreadsheet contents, archive access, deployed triggers, web-app deployment, and effective authorizations require verification in the target Apps Script container.
- Format Dashboard Section B–H validation reports missing or empty required sections rather than creating them automatically.
- Automatic archive deletion remains disabled when `RFF_ENABLE_AUTO_ARCHIVE_RAW_DATA` is explicitly set to `false`; in that mode local imported source tabs are preserved.
