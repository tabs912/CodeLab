# Master List v1.93.1 Release Notes

## Release

- **Version:** v1.93.1
- **Production candidate:** `Master_List/Current Production Script/v1.93.1`
- **Rollback reference:** `Master_List/Current Production Script/v1.93`
- **Input specification:** `Master_List/Audit Summary/v1.93/v1.93 Menu Updates.pdf` (review input only; not included in this implementation commit)

## Functional summary

v1.93.1 is a corrective release for the v1.93 system-startup failure, dashboard structural metadata, template grid sizing, menu connectivity, monthly formatter source handling, and Dashboard Quality process coverage. The immutable v1.93 rollback source remains unchanged.

## Change log

1. **Corrected Quick System Setup order.** The workflow now creates the base template, default Format Dashboard, Framework Timing template, Dashboard Quality template, and Index template before creating their active sheets. Dashboard Quality therefore no longer runs before `Dashboard Quality Report` exists.
2. **Added self-healing Dashboard Quality creation.** A direct quality command creates its governed template and active report when they are absent, while still failing explicitly if creation cannot complete.
3. **Aligned menu actions with the supplied layout.** Maintenance/Rebuild contains the specified Quality and System actions. Start-up exposes separate Create System Sheet Templates and Create Active System Sheets actions. All registered callbacks resolve exactly once.
4. **Completed Dashboard Quality Sections C-H.** The workflow writes Raw Data, Refined Data, Disenrolled Exclusion, Monthly Change, Master List, and summary validation sections in addition to Sections A-B.
5. **Populated Section C Column Count.** Operational counts now equal each template's governed Section G header count. System counts reflect their actual output matrices: Timing 7, Quality 3, Format Dashboard 19, and Index 10.
6. **Added one-column grid buffers.** Newly built templates and copied active/output sheets are trimmed to their required row count and governed content-column count plus exactly one blank buffer column.
7. **Corrected Section D governance.** Raw Data now belongs to `Monthly Active`.
8. **Completed template creation coverage.** Create / Refresh All Templates also refreshes `RFF_BASE_TEMPLATE` and `Template - Archive - Refined Data`.
9. **Corrected monthly source behavior.** The formatter can resolve code-named imports, renames the Raw Data import to `Source - Raw Data mm.yy`, does not archive Raw Data, and continues to require verified archive copies before deleting Banner, CP Due, or Unlock CP imports.
10. **Preserved compatibility.** Existing public workflow entry points remain defined even when the supplied menu no longer presents their individual maintenance shortcuts.

## Dependencies and permissions

- Google Apps Script V8 runtime.
- Container-bound Google Spreadsheet access.
- Document properties for timing state, archive spreadsheet ID, archive enablement, saved dashboard defaults, and Index restore URL.
- Drive/Spreadsheet permission to the configured archive workbook for archive-enabled sub-report formatting.
- Authorization for Spreadsheet, Properties, Lock, Utilities, and HTML services used by the script.

## Performance impact

- Template creation performs one bounded grid trim after formatting. This removes surplus rows/columns and reduces later whole-grid formatting work.
- Dashboard Quality adds five small process checks and one summary write.
- Quick System Setup performs deterministic template construction before active-sheet copying; this adds expected setup work but removes the failed partial-startup state.

## Test plan

1. Run **Create System Sheet Templates** in a workbook with no system templates; verify all five governed template surfaces exist.
2. Run **Create Active System Sheets**; verify Format Dashboard, Framework Timing Report, Dashboard Quality Report, and Index exist.
3. Delete Dashboard Quality Report and run **Dashboard Quality Start up**; verify it is recreated and Section A is written.
4. Run **Dashboard Quality Workflow**; verify Sections A-H are written and missing optional monthly outputs report warnings rather than false failures.
5. Build all templates; for each, verify `max columns = Section C Column Count + 1` and the final column is blank.
6. Format each monthly import and verify outputs retain one blank buffer column.
7. Verify Raw Data source is renamed but not copied to the archive workbook; verify the three sub-report sources are deleted only after archive-copy verification.
8. Exercise every visible menu item and verify the registered callback performs the described action.

## Known runtime-dependent items

- Live archive access, workbook-specific imported headers, deployed triggers, and web-app deployment cannot be proven outside the bound Apps Script workbook.
- Existing workbooks must rebuild the default and active Format Dashboard to receive the corrected Section C counts and Section D Raw Data group.
- Existing templates must be refreshed to receive the exact one-column buffer dimensions.
