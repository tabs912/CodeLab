# Master List v1.9.3.2 Release Notes

## Release identification

- **Version:** v1.9.3.2
- **Production candidate:** `Master_List/Current Production Script/v1.9.3.2`
- **Immediate predecessor:** `Master_List/Current Production Script/v1.93.1`
- **Rollback source:** `Master_List/Current Production Script/v1.93.1`
- **Correction inputs reviewed:** `v1.9.3.1 Updates.md` and `Working Sub-headers.txt` from `Master_List/Audit Summary/v1.93/`.

## Functional summary

v1.9.3.2 restores working template subheaders, confines system-sheet formatting to template construction, appends Timing and Quality data at governed subheader data positions, expands native banding through the blank buffer column, applies tab ranking to all creation paths, restores the requested maintenance menu groups, and completes the requested concurrency, configuration, telemetry, and Spreadsheet API corrections.

## Corrections and change log

1. **Restored governed subheaders.** Timing, Dashboard Quality, and Monthly Change template block definitions are restored from the working reference. Each block uses the six-step Section B2 layout: blank row, title, spacer, header, blank row, and data-entry row.
2. **Section B formatting governance.** Title rows consume parsed Section B settings. Subheader rows consume parsed Section B2 settings for row height, fill, font size/weight, alignment, and wrapping.
3. **Template-only system formatting.** Active system sheets are copied from fully formatted templates. Active creation only stamps values and timestamps. Index refresh no longer reapplies active-sheet formatting. Dashboard Quality applies only the approved red failure highlight after writing data.
4. **Governed result placement.** Timing records append under `SECTION D - DETAILED TIMING LOG`. Quality records append four rows below their subheader title or after existing results, inserting data rows before the next governed section when necessary.
5. **Buffer-column banding.** Native banding spans the content columns and the one-column buffer on every template, including the Format Dashboard.
6. **Creation rank coverage.** Base templates, operational/system templates, copied active sheets, restored archive sheets, and fallback-created operational outputs all invoke governed tab placement.
7. **Menu restoration.** Maintenance/Rebuild again includes Format Sheets and Data Processing. The Demo P submenu maps Update and Build actions to the governed Refined Data implementations, and all visible callbacks resolve.
8. **Refined concurrency.** `runFrameworkTimed_` no longer obtains a document lock. Seven write-heavy/destructive workflows now independently acquire a 30-second document lock and release it in `finally`.
9. **Centralized system names.** `SYSTEM_SHEETS` is the single source for the Format Dashboard, default dashboard, Index, Timing, Quality, base template, template prefix, and source prefix names.
10. **Observable best-effort failures.** Every formerly empty catch block now records the failure through `logBestEffortWarning_`.
11. **Reduced Spreadsheet service calls.** Layout workflows cache the active spreadsheet once and pass it into nested ranking operations where applicable.
12. **Preserved prior corrections.** Section C governed column counts, Raw Data's Monthly Active grouping, one-column buffers, Dashboard Quality self-healing, and verified archive-before-delete behavior remain present.

## Dependency impact

- No new external library dependency.
- Requires the Google Apps Script V8 runtime and the existing Spreadsheet, Properties, Lock, Utilities, HTML, and Logger services.
- Archive-enabled operations still require a valid `RFF_ARCHIVE_SPREADSHEET_ID` and workbook access.
- Existing documents must rebuild templates to receive subheaders, revised banding, and template-only system formatting.

## Performance impact

- Read-only timed workflows no longer serialize behind the global timing wrapper.
- Write locks are limited to seven workflows that mutate operational data, archive sheets, replace sheets, or build reports.
- Active Index refresh avoids a second formatting pass.
- Cached spreadsheet objects reduce redundant service gateway calls during tab organization.

## Test plan

2. Confirm title formatting follows Format Dashboard Section B and subheader formatting follows Section B2.
3. Create active system sheets and verify their formatting is inherited without an active formatting pass.
4. Run Timing and Quality workflows twice; confirm results append at the end of the correct section and do not overwrite the next section.
5. Force a Quality failure and confirm only the failed status cell receives the red highlight.
6. Verify native banding reaches the last blank buffer column.
7. Exercise all menu commands and verify callback/action connectivity.
8. Run concurrent read-only quality checks and confirm `runFrameworkTimed_` does not block them.
9. Exercise each locked write workflow and confirm lock timeout errors are explicit and locks release after success or failure.
10. Create every supported sheet through normal and fallback paths; verify governed rank placement.

## Known runtime-dependent items

- Live concurrency, archive permissions, workbook-specific schemas, deployed triggers, and web-app deployment must be validated in the bound Apps Script project.
- Existing active system sheets are not retroactively reformatted; rebuild templates and recreate the active system sheets to adopt this release.
