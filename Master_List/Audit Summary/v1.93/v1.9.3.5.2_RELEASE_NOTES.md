# v1.9.3.5.2 Release Notes

## Functional summary

`v1.9.3.5.2` updates the Format Monthly Sheets workflow so every non-Raw-Data source tab is copied to the configured archive workbook before the governed output sheet factory applies its overwrite policy.

This preserves Banners, CP Due Date, and Unlocked CP source imports in the archive workbook even when the imported CP Due Date or Unlocked CP tab already has the same name as the governed monthly output tab.

## Change log

- Created new production version `Master_List/Current Production Script/v1.9.3.5.2` from `v1.9.3.5.1`.
- Updated the production version constant and script metadata references to `v1.9.3.5.2`.
- Moved verified non-Raw-Data source archiving ahead of `createGovernedSheet_` in `processSingleSubReport_`.
- Added source sheet ID tracking so the local source tab is deleted only if it still exists after governed output creation.
- Preserved Raw Data behavior: Raw Data remains local, is renamed to the governed source name, and is hidden instead of archived/deleted.

## Dependency impact

- No public menu functions, helper signatures, dashboard schema, configuration keys, triggers, or manifest settings were changed.
- The workflow still depends on a valid `RFF_ARCHIVE_SPREADSHEET_ID` and verified access to the archive spreadsheet before deleting non-Raw-Data source tabs.

## Performance impact

- No additional archive workbook opens or source-copy operations were added.
- The change reorders the existing archive copy before governed output creation and adds a single in-memory sheet ID lookup before optional source deletion.

## Test plan

1. Import monthly Banners, CP Due Date, Unlocked CP, and Raw Data source tabs for the same prompted month.
2. Run `menuFormatMonthlySheets` or the equivalent monthly formatting menu item.
3. Verify archive workbook tabs are created for `Source - Banners mm.yy`, `Source - CP Due mm.yy`, and `Source - Unlocked CP mm.yy`.
4. Verify local governed output tabs are created for `Banners mm.yy`, `CP Due mm.yy`, `Unlock CP mm.yy`, and `Raw Data mm.yy`.
5. Verify local non-Raw-Data source tabs are deleted only after archive verification succeeds.
6. Verify local Raw Data source is preserved as `Source - Raw Data mm.yy` and hidden.
7. Simulate archive access failure and verify processing stops before deleting the local non-Raw-Data source tab.

## Known issues intentionally unchanged

- Raw Data is intentionally not archived by this workflow.
- A failed individual monthly route is still reported through the existing route result handling while the broader formatter continues according to existing behavior.

## Rollback reference

Rollback to `Master_List/Current Production Script/v1.9.3.5.1` if this release must be reverted.
