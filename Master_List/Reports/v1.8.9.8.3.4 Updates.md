# Master List v1.8.9.8.3.4 Updates

## Release purpose

Version **v1.8.9.8.3.4** completes the production-source ownership quarantine started in v1.8.9.8.3.2. All Format Dashboard default section settings and direct population architecture for governed system sheets now reside beneath the **SYSTEM SHEETS, DIAGNOSTICS & FORMAT DASHBOARD** banner.

## Implementation

- Moves all eight Format Dashboard default section inventories into the quarantine, including the previously omitted Section G column-definition defaults.
- Moves Index constants, shell construction, local/archive data writers, update/create wrappers, restore web-app handlers, deferred refresh, and tab-organization helpers into the system-sheet section.
- Moves the **Archive - Refined Data** system-surface constants and direct archive-sheet creation/header/value writers into the system-sheet section.
- Moves archive workbook configuration/open-once helpers used by Index and system archive population into the same ownership section.
- Updates the quarantine inventory to **57 constants, 2 mutable state values, and 314 functions**.
- Preserves core monthly, Master List, Refined Data, Monthly Change, Banner, and Disenrolled workflow bodies above the quarantine; those workflows call the relocated system-sheet interfaces without implementation changes.

## Compatibility

- Existing public callback names, signatures, menu bindings, and deployment interfaces remain unchanged.
- Existing v1.8.9.8.3.2 function bodies are preserved; declarations are relocated without logic changes.
- `RFF_BASE_TEMPLATE` ownership and all approved business-processing rules remain unchanged.
- The production version advances from **v1.8.9.8.3.2** to **v1.8.9.8.3.4**.

## Required runtime validation

1. Run `rebuildFormatDashboardDefaults()` and verify Sections A–H, including the complete Section G column-definition inventory.
2. Run `setupSystemSheets()` and `createSystemTemplates()`.
3. Run `updateIndexSheet()` with local and archive workspaces available.
4. Execute a Refined Data monthly sync that appends rows to **Archive - Refined Data**.
5. Run Dashboard Quality and Framework Timing workflows.
6. Run Monthly Start and Monthly Update and compare outputs with v1.8.9.8.3.2.
