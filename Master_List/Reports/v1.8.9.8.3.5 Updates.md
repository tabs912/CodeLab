# Master List v1.8.9.8.3.5 Updates

## Release purpose

Version **v1.8.9.8.3.5** reorganizes the production source into seven explicit ownership sections aligned to the custom menu and framework lifecycle. Approved processing behavior is unchanged; complete function declarations are relocated as organizational units.

## Production layout

1. **Create Monthly Update / Start** — Monthly Start, Monthly Update, Refined Data, Disenrolled Exclusion, Monthly Change, Master List, and their exclusive helpers.
2. **Format Monthly Sheets** — monthly formatter orchestration and Banner, Care Plan Due, Unlocked Care Plan, and Raw Data formatter paths.
3. **Sheet & Layout Management** — monthly hide/archive operations, template and system-sheet visibility callbacks, layout snapshots, and global sheet ordering.
4. **Build Template** — report-template build, refresh, staging, promotion, validation, formatting, and build-menu callbacks.
5. **Index** — Index constants, shell, local/archive population, update/create/restore callbacks, web-app restore, and deferred refresh.
6. **Base Template / Master Template** — protected `RFF_BASE_TEMPLATE` and golden-master synchronization lifecycle.
7. **System Sheets, Diagnostics & Format Dashboard** — Format Dashboard, Dashboard Quality Report, Framework Timing Report, System setup, diagnostics, menus, and related constants/state.

## Governance and compatibility

- Section 7 is the final section in the source and quarantines only the three governed diagnostic/configuration sheets and shared system setup architecture.
- Menu callbacks are assigned to their requested ownership sections while `onOpen()` and `ML_MENU_CALLBACKS` remain in Section 7.
- Shared foundational utilities used by multiple sections remain in the pre-section core utility area to avoid duplication.
- Every function name and constant name remains unique.
- Existing v1.8.9.8.3.4 function bodies are preserved; only declaration order and the production version change.
- Public callbacks, wrappers, property keys, archive interfaces, and approved business rules remain unchanged.

## Required runtime validation

1. Open the workbook and verify every custom-menu command resolves.
2. Run Monthly Start and Monthly Update.
3. Run all four monthly formatter routes.
4. Run hide/archive and sheet-order commands.
5. Run `buildAllTemplatesAndValidate()` and Base Template synchronization.
6. Run Index build/update/restore tests.
7. Run System setup, Format Dashboard rebuild, Dashboard Quality, and Framework Timing workflows.
