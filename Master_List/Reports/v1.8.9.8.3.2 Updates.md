# Master List v1.8.9.8.3.2 Updates

## Release purpose

Version **v1.8.9.8.3.2** reorganizes the v1.8.9.8.3.1 production source without changing approved report-processing behavior. System Sheets, Format Dashboard, Framework Timing Report, Dashboard Quality Report, menu, diagnostics, and their exclusive support declarations are quarantined at the bottom of the production file.

## Implementation

- Moves 46 system/diagnostic constants, 2 mutable Dashboard Quality state values, and 274 related functions beneath the **SYSTEM SHEETS, DIAGNOSTICS & FORMAT DASHBOARD** ownership banner.
- Keeps core Master List, Refined Data, Monthly Change, Banner, and other business processors above the quarantine boundary.
- Preserves every pre-existing function body byte-for-byte except `onOpen()`, which receives the requested System submenu item.
- Adds `createSystemTemplate()` and `createSystemTemplates()` as the canonical Section E-driven system-template rebuild entry points.
- Adds `createSystemTemplates` to `ML_MENU_CALLBACKS.maintenanceRebuild` and places **Rebuild System Templates** first in the Maintenance/Rebuild → System submenu.
- Preserves the `RFF_BASE_TEMPLATE_NAME` guard so system-template rebuilding cannot create the protected base report template.
- Moves the remaining Dashboard Quality testing runners, section-state helpers, required-function checks, and Framework Timing support helpers into the same quarantine section.
- Removes relocation artifacts by collapsing excessive blank-line runs throughout the production source.

## Compatibility

- Existing public callback names and signatures remain available.
- Existing report-processing functions, mappings, arrays, and helper bodies are unchanged.
- Apps Script function declaration hoisting allows core processors to call quarantined helpers after source reorganization.
- The production version is advanced from **v1.8.9.8.3.1** to **v1.8.9.8.3.2**; no OAuth, property-key, trigger, archive, or deployment change is introduced.

## Required runtime validation

1. Open the workbook and confirm the custom menu renders without errors.
2. Confirm **Maintenance/Rebuild → System → Rebuild System Templates** is the first System submenu item.
3. Run `createSystemTemplates()` and confirm all Section E system surfaces except **RFF_BASE_TEMPLATE** are rebuilt and formatted.
4. Run `setupSystemSheets()`, Dashboard Quality, Framework Timing, and Format Dashboard workflows.
5. Run Monthly Start and Monthly Update and compare business outputs with v1.8.9.8.3.1.
