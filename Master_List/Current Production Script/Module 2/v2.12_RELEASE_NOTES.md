# Module 2 v2.12 Release Notes

## Summary

Module 2 v2.12 adds a mandatory sheet-governance preflight before the governed factory creates any sheet.

## Changes

- Added `resolveSheetGovernance_()` to evaluate sanitized name, collision policy, visibility, rank, dynamic rank, group, tab color, protected-system safeguards, and insertion index.
- Added `getRankForSheetName_()` to resolve existing-sheet ranks from Dashboard Section B creation rules.
- Added `calculateDynamicRank_()` with numeric/object dynamic-rule support and a safe active-rank fallback.
- Integrated the returned governance blueprint into `createGovernedSheet_()` before `copyTo()` or `insertSheet()` is called.
- Protected `Format Dashboard` and `RFF_BASE_TEMPLATE` from automated overwrite.
- Supported `OVERWRITE`, `INCREMENT`, `ABORT`, and legacy `FAIL` collision policies.
- Validated the template mold before an overwrite collision can delete an existing output.
- Applied the blueprint name, insertion index, visibility, rank, group, and optional tab color to the new sheet.

## Preserved behavior

- Module 2 v2.11 remains the implementation base.
- CP Due and Unlock CP source-date processing remains unchanged.
- Raw Data source-only column preservation and post-write verification remain unchanged.
- Dashboard Section G number formats remain active.
- Public menu callbacks and signatures remain unchanged.

## Test plan

1. Build a governed sheet with no collision and confirm the preflight timing step appears before sheet creation.
2. Test `OVERWRITE`, `INCREMENT`, `ABORT`, and `FAIL` collisions.
3. Attempt to overwrite `Format Dashboard` and `RFF_BASE_TEMPLATE`; confirm both abort.
4. Test a name containing invalid characters and a name longer than 100 characters.
5. Verify static rank placement and alphabetical tie-breaking.
6. Verify a numeric and object `dynamicRankRule`.
7. Verify template outputs are hidden and use template rank.
8. Remove a required template mold and confirm the existing output is not deleted.
9. Re-run Format Monthly Sheets and confirm source dates, Raw Data preservation, and Section G number formats still pass.

## Known issues unchanged

- The preflight performs the configured overwrite deletion before the replacement sheet is copied; staged replacement is outside this release.
- Other documented processing-parity findings remain outside this release.
