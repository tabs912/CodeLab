# Module 2 v2.15 Release Notes

## Summary

Module 2 v2.15 makes missing Format Monthly import reports fatal before any requested report is mutated and records the Raw Data preserved-source lifecycle as approved.

## Changes

- Added a batch import preflight before Banners, CP Due, Unlock CP, or Raw Data processing begins.
- Validates every requested route with the existing source-sheet resolver.
- Throws one fatal error listing all missing required imports for the prompted month.
- Runs before source archiving, governed output creation, source renaming, hiding, or deletion.
- Retains per-route error isolation for processing errors that occur after all required imports pass preflight.

## Approved Raw Data lifecycle

- Keep the governed Raw Data output.
- Keep the original imported Raw Data as the hidden `Source - Raw Data mm.yy` sheet.
- Continue appending and verifying imported columns that are not declared in Dashboard Section H.
- This is an approved modular design difference from v1.8.9.3 in-place Raw Data formatting.

## Test plan

1. Remove one requested import and confirm the fatal error lists it before any source or output changes.
2. Remove multiple requested imports and confirm one fatal error lists all missing reports.
3. Supply all imports and confirm the four Format Monthly routes run normally.
4. Confirm Raw Data output and hidden preserved source both remain after successful formatting.
