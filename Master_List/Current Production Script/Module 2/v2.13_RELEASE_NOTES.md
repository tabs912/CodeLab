# Module 2 v2.13 Release Notes

## Summary

Module 2 v2.13 standardizes Refined Data terminology, restores Refined Data phone/notes processing, preserves Disenrolled Exclusion history, and removes the redundant Banner source from Master List synthesis.

## Changes

- Replaced remaining Demo P terminology and tracking headers with Refined Data terminology.
- Preserved the v1.8.9.3 four-slot phone rules: underscore-delimited values, `Home`, `Mobile`, `Other`, `Other` labels, and clearing unused slots.
- Restored the dedicated Notes combination after Banner and contact processing.
- Notes combine Banner Summary, Contact Summary, PCP/RN/Social Work caseloads, and Additional Important Information when Notes is blank.
- Disenrolled Exclusion is no longer overwritten during monthly processing.
- Monthly Start appends all Refined Data disenrollments not already retained.
- Monthly Update inserts new disenrollments at row 5 above historical rows.
- Added targeted removal of exclusion rows only for PMRs identified as active/re-enrolled in Refined Data.
- Added an explicit equality assertion before disenrolled rows are removed from Refined Data.
- Removed Banners as a Master List source because Banner synchronization is completed during Raw Data formatting.

## Approved decisions

- Master List uses standard governance collision handling; no separate replacement prompt is added.
- Master List is not staged before replacement because it is a third-generation output.
- Master List does not apply a Primary PMR Row filter because Refined Data contains one participant row per PMR.

## Test plan

1. Build Refined Data and verify all four phone slots and labels against v1.8.9.3 examples.
2. Verify Notes combines Banner, contact, selected caseload, and additional-information values in the approved order.
3. Run Monthly Start with historical disenrollments and confirm they are appended to Disenrolled Exclusion.
4. Run two Monthly Updates and confirm each new set is inserted at row 5 while prior rows remain.
5. Re-enroll one PMR and confirm only that PMR is removed from Disenrolled Exclusion.
6. Force an append-count mismatch and confirm Refined Data is not rewritten.
7. Build Master List without a Source - Banners sheet and confirm Banner columns arrive from Refined Data.

## Known issues unchanged

- Monthly Update selective replacement and other previously documented parity findings outside this request are unchanged.
