# Module 2 v2.16 Release Notes

## Changes

- Moved the sheet-governance note from `F1` to `B1`.
- Removes a legacy `[Sheet Governance]` block from the `F1` note while preserving any unrelated note text.
- Added non-destructive governance-note application for existing system sheets and templates.
- Added dynamic month rank calculation using `Base Rank + ((12 - Month Number) × 22)`.
- December uses the zero-month offset, so December retains the base rank.
- Existing governed output creation continues to write rank metadata after final positioning.

## Test plan

1. Create active, system, and template sheets and verify the governance block is in the `B1` note.
2. Verify no governance block remains in `F1`.
3. Verify December ranks equal their configured base ranks.
4. Verify November adds 22, October adds 44, and January adds 242.
5. Verify identical monthly ranks sort alphabetically only as a tie-breaker.
