# Module 2 v2.17.3 Release Notes

## Functional summary

Formatted Raw Data sheets now display a participant summary in cell G1. Counts
are based on unique `Participant PMR#` values rather than Raw Data row counts.

## Change log

- Calculate the total number of unique participants.
- Calculate unique participants whose `Enrollment Status` is `Enrolled`.
- Calculate unique participants whose `Enrollment Status` is `Disenrolled`.
- Write all three labeled totals to G1 on separate wrapped lines.
- Validate that the governed Section H PMR and enrollment-status headers exist.

## Dependency and performance impact

The calculation uses the already-loaded Raw Data matrix and three in-memory
`Set` collections. It adds no full-sheet read and only one cell write.

## Test plan

1. Format Raw Data containing repeated rows for the same PMR.
2. Confirm G1 counts each PMR only once in the overall total.
3. Confirm status matching is case-insensitive and trims surrounding spaces.
4. Confirm blank PMRs are excluded.
5. Confirm G1 reports the three labels and totals on separate lines.

## Known issues intentionally unchanged

A participant appearing with both governed statuses is counted once in each
matching status total, while remaining a single participant in the overall
total.
