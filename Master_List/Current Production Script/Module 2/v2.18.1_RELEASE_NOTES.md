# Module 2 v2.18.1 Release Notes

## Functional summary

Format Raw Data now removes non-primary rows for participants whose
`Disenrollment Effective Date` is more than one calendar year before the
prompted report month’s end date. The governed Primary PMR Row is retained.

## Change log

- Calculate the one-year cutoff from the prompted report end date.
- Identify aged disenrollments by unique `Participant PMR#`.
- Remove only non-primary rows for identified participants.
- Preserve all rows for recent, future, blank, or invalid effective dates.
- Add framework timing details for removed rows and affected participants.
- Validate all required governed headers and the report end date.

## Dependency and performance impact

The pruning pass uses the already-mapped Raw Data matrix and one in-memory PMR
set. It adds no Spreadsheet service reads or writes and runs before banner
synchronization and governed sheet creation.

## Test plan

1. Format Raw Data with a participant disenrolled more than one year before the
   prompted month end and verify only the Primary PMR Row remains.
2. Verify a date exactly one year before month end is not pruned.
3. Verify recent, future, blank, and invalid dates retain all rows.
4. Verify participant totals and downstream workflows use the pruned Raw Data.

## Known issues intentionally unchanged

Primary-row selection logic, Section H column governance, and source-sheet
preservation remain unchanged.
