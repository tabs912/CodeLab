# Module 3 v2.0.14 Release Notes

## Functional summary

Template title-row formatting is now resolved directly from Format Dashboard
Section E, and subheader-block formatting is resolved directly from Section F.

## Change log

- Add a single dashboard-section row-spec resolver.
- Require title formatting to use the parsed Section E `titleRows` collection.
- Require both new and existing subheader blocks to use the parsed Section F
  `subheaderRows` collection.
- Apply GLOBAL rows plus any matching sheet-specific rows.
- Fail clearly when Section E or Section F is absent or has no applicable rows.
- Remove the template builder's reliance on caller-provided formatting arrays as
  an independent formatting authority.

## Dependency and performance impact

Public template entry points and the dashboard schema are unchanged. Resolution
filters small in-memory dashboard collections and adds no Spreadsheet service
calls.

## Test plan

1. Change a Section E title-row property and rebuild an operational template.
2. Verify title rows 1-4 reflect the changed Section E value.
3. Change a Section F subheader-row property and rebuild Monthly Change.
4. Verify every six-row subheader block reflects Section F.
5. Remove either section in a test dashboard and verify template creation stops
   with a section-specific configuration error.

## Known issues intentionally unchanged

Section G continues to govern column widths, number formats, and other
column-specific formatting.
