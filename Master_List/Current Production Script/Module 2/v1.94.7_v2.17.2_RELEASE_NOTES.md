# Module 1 v1.94.7 / Module 2 v2.17.2 Release Notes

## Functional summary

Every Monthly Change subheader section is now corrected at report creation time
to contain the complete ordered Monthly Change header list from Format Dashboard
Section H. Appending report data no longer pastes cell backgrounds over native
alternating banding.

## Change log

- Pass the active dashboard configuration into Monthly Change subheader loading.
- Validate that Section H contains Monthly Change headers.
- Rewrite every report subheader header row from the complete Section H list,
  including reports copied from an older template.
- Remove `PASTE_FORMAT` from subheader data appends because it overwrote native
  banding backgrounds.
- Apply yellow change highlighting only to changed cells instead of rewriting
  the complete data-range background matrix.
- Preserve the Section F data-row height without changing cell backgrounds.

## Dependency and performance impact

Public entry points and comparison logic are unchanged. Report creation adds one
batched header-row write per Monthly Change section and removes a full-width
format copy for every appended data block.

## Test plan

1. Build a Monthly Change report from both a current and an older template.
2. Verify all eight subheader header rows exactly match Section H in order.
3. Append multiple rows to every populated section and verify native alternating
   banding remains visible and expands through the added rows.
4. Verify inserted data rows retain the Section F data-row height.

## Known issues intentionally unchanged

Change detection, yellow changed-field highlighting, section routing, and tab
ranking remain unchanged.
