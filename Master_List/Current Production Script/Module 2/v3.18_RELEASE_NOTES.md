# Module 5 Aligned Format Dashboard Section Layout — v3.18

## Functional summary

`BuildDefaultFormatDashboard()` now writes Sections A–H using the same six-step row structure as the general-template subheader builder. The first section block begins on row 6, and the data writer no longer adds four redundant blank rows after every section.

## Change log

- Reserved rows 3–5 for the governed title spacer, header row, and pre-section buffer.
- Began the first dashboard subheader block on row 6.
- Wrote each section as: blank row, section title, visual spacer, governed headers, data buffer, and data.
- Removed the four-row tail previously appended after every completed section.
- Retained one separator row by using the next section block's leading blank row.
- Preserved `formatExistingSections` so the general-template build formats the populated rows without creating a duplicate set of subheaders.
- Incremented the dashboard Template Version to 3.18.

## Dependencies and compatibility

- Deploy with the other current versions listed in `CURRENT_MODULES_README.md`.
- `BuildDefaultFormatDashboard()` and `buildFormatDashboardTemplate_()` signatures are unchanged.
- Saved dashboards remain readable because section discovery is title-based rather than fixed-row based.

## Test plan

1. Run `BuildDefaultFormatDashboard()`.
2. Confirm rows 3–5 are blank and the first subheader block begins on row 6.
3. Confirm the first section title is on row 7 and its governed headers are on row 9.
4. Confirm only one leading separator row exists between completed section data and the next section title block.
5. Confirm there are no four-row tails after sections.

## Known issues

- Existing dashboards are not automatically compacted; rebuild the Default - Format Dashboard to receive the corrected layout.
