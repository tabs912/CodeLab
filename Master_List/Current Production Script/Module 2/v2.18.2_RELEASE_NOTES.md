# Module 2 v2.18.2 Release Notes

## Functional summary

Format Raw Data now enforces a post-condition that the imported source sheet’s
cell contents remain unchanged. Pruning, banner synchronization, totals, and
formatting continue to affect only the newly governed Raw Data output matrix.

## Change log

- Retain the original source headers and data matrix as the pre-format snapshot.
- Re-read and compare the source after governed output processing.
- Stop with a precise row/column integrity error if source content changed.
- Record successful source-integrity verification in framework timing.
- Preserve the existing lifecycle behavior that renames the import to
  `Source - Raw Data mm.yy` and hides the source tab.

## Dependency and performance impact

The check adds one batched source-data read and an in-memory comparison. It does
not write to, clear, prune, resize, or format the source sheet.

## Test plan

1. Format Raw Data containing aged disenrollment contact rows.
2. Verify the governed Raw Data output is pruned as configured.
3. Verify every source header and data value remains unchanged.
4. Confirm the source is renamed and hidden only after integrity verification.
5. Mutate a source value in a controlled test and verify the workflow stops with
   the source row and column in the error.

## Known issues intentionally unchanged

Lifecycle governance still renames and hides the source tab; “untouched” refers
to its cell content and formatting, not its governed tab name or visibility.
