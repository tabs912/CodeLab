# Module 5 Slash-Delimited Dashboard Defaults — v3.17

## Functional summary

The single Format Dashboard defaults matrix now expresses per-column Title Date Format, Default Column Widths, and targeted Section E/F formatting with `/` separators. Blank positions between separators intentionally make no change to that column.

## Change log

- Converted all populated Section C Default Column Widths lists from commas to `/` separators.
- Added the requested `14/ /5` Section E row-1 Font Size default.
- Added matching per-column Font Weight, Alignment, and Wrap defaults for title cells A and C.
- Added slash-delimited A/C defaults for the title-date row and subheader title row.
- Incremented the dashboard Template Version to 3.17.

## Dependencies and compatibility

- Requires Module 3 v2.0.6 for slash-only width parsing and blank-position preservation.
- `MASTER_FORMAT_DEFAULTS` remains the sole literal Format Dashboard default-data declaration.
- Existing dashboard build and restore entry points are unchanged.

## Test plan

1. Run `BuildDefaultFormatDashboard()`.
2. Inspect Sections C, E, and F for slash-delimited values.
3. Build a general template and verify A/C formatting and blank-position behavior.
4. Build Timing and Quality templates and verify their slash-delimited widths.

## Known issues

- Literal slashes are reserved as column separators in the governed fields.
