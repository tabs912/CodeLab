# Module 2 v2.11 Release Notes

## Summary

Module 2 v2.11 uses valid CP Due and Unlock CP source-report dates and adds runtime verification that Raw Data columns outside Dashboard Section H retain their imported values.

## Changes

- CP Due reads its output start and end dates from source cells `C3` and `E3`.
- Unlock CP reads its output start and end dates from source cells `E2` and `G2`.
- An invalid or blank source date falls back to the corresponding prompted-month date and records a warning.
- Raw Data still appends every unique source-only header after the governed Section H headers.
- After writing Raw Data, the workflow reads the formatted output and verifies every source-only value for every nonblank imported row.
- A missing header or changed value causes the RD route to fail instead of reporting successful preservation.

## Preserved behavior

- Module 2 v2.10 remains the implementation base.
- Dashboard Section G number formats remain active.
- Governed Section H columns remain in their configured order.
- Banners, CP Due, and Unlock CP archive behavior is unchanged.
- Public menu callbacks and signatures are unchanged.

## How to verify Raw Data preservation

1. Add two test columns to an RD import that do not exist in Dashboard Section H.
2. Populate them with distinct text, number, blank, and date values across several rows.
3. Run **Format Monthly Sheets** or **Format Raw Data**.
4. Confirm the two headers appear after the governed Raw Data columns.
5. Confirm their values match the import.
6. Review Framework Timing for `Raw Data - Verify source-only columns`; it reports the verified column and row counts.
7. Any mismatch throws `Raw Data preservation verification failed` and marks the RD route unsuccessful.

## Test plan

2. Set valid Unlock CP dates in `E2` and `G2`; verify output `B2` and `D2` match them.
3. Test one invalid source date and verify only that value uses the prompted-month fallback.
4. Run the Raw Data preservation procedure above.
5. Verify Section G number formats still apply to governed columns.
6. Run Create Monthly Start and confirm Refined Data still maps governed Raw Data columns.

## Known issues unchanged

- This release does not change the modular Raw Data source/output lifecycle.
- Other documented parity findings remain outside this release.
