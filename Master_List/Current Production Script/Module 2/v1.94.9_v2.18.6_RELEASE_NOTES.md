# Module 1 v1.94.9 / Module 2 v2.18.6 Release Notes

## Functional summary

Every individual format trigger under Rebuild / Maintenance now formats the
currently selected sheet. The source tab no longer needs to match a naming
pattern such as `Raw Data 04.26`; a current sheet named `RD` is accepted.

The batch **Format Monthly Sheets** workflow retains its existing named-source
discovery and all-import preflight behavior.

## Change log

- Route Format Banner Report to the active sheet.
- Route Format CP Due Date Report to the active sheet.
- Route Format Unlocked CP Report to the active sheet.
- Route Format Raw Data to the active sheet.
- Capture the active sheet once before individual-format preflight and processing.
- Reject template tabs and active-sheet requests containing more than one report
  type.
- Preserve named source discovery for the four-report batch formatter.
- Add timing details identifying the active source sheet.

## Dependency and performance impact

No additional Spreadsheet reads are required beyond obtaining the active sheet.
The existing formatter, archive, Raw Data numbering, integrity, and governance
paths run unchanged after source selection.

## Test plan

1. Select an unformatted sheet named `RD` and run Format Raw Data.
2. Verify no missing `Raw Data mm.yy` preflight error occurs.
3. Repeat with arbitrarily named Banner, CP Due Date, and Unlock CP imports.
4. Select a Template tab and verify the individual formatter stops safely.
5. Run Format Monthly Sheets and verify it still requires all four named imports.

## Known issues intentionally unchanged

The user must select the intended unformatted source before invoking an
individual format trigger. Batch formatting remains name-driven.
