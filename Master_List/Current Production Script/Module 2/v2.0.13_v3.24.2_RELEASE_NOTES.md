# Module 3 v2.0.13 / Module 5 v3.24.2 Release Notes

## Functional summary

Monthly Change template subheader rows now retain the formatting configured in
Format Dashboard Section F. Every Monthly Change subheader header row is also
populated from the governed Monthly Change header list in Section H.

## Change log

- Reapply Section F formatting after operational column formatting so the
  latter cannot replace subheader alignment and wrap settings.
- Replace hardcoded, section-specific Monthly Change subheader header arrays
  with copies of the Section H Monthly Change sheet headers.
- Fail clearly when Section H has no Monthly Change headers.
- Increment the Format Dashboard template version to 3.24.2.

## Dependency and performance impact

Public workflow entry points and the dashboard schema are unchanged. Template
creation performs one additional in-memory Section F formatting pass over the
eight Monthly Change subheader blocks.

## Test plan

1. Build `Template - Monthly Change` from the current Format Dashboard.
2. Verify all six rows in every subheader block match Section F height, fill,
   font, alignment, and wrap settings.
3. Verify every subheader header row exactly matches the ordered Monthly Change
   headers in Section H.
4. Change a Section F style and a Section H header, rebuild the template, and
   confirm both changes appear without code edits.

## Known issues intentionally unchanged

The eight Monthly Change section titles, comparison logic, output routing, and
dynamic tab ranking are unchanged.
