# Module 2 v2.18.7 Release Notes

## Functional summary

Format Raw Data no longer inserts or populates the source `#` column. The
unformatted source is expected to arrive pre-numbered, and those existing values
are copied into the governed formatted Raw Data `#` column.

## Change log

- Remove source column insertion from Format Raw Data.
- Remove generated sequential row numbers from Format Raw Data.
- Validate that the unformatted Raw Data source already contains `#`.
- Preserve and map the existing source `#` values through Section H.
- Keep `#` in the Format Dashboard schema and Raw Data template build.
- Restore source integrity to cover the complete import, including `#`, from the
  first source snapshot onward.

## Dependency and performance impact

The formatter removes one source column insertion and one source value write.
The existing in-memory header mapper copies `#` without additional Spreadsheet
service calls.

## Test plan

1. Select a pre-numbered source containing `#` and run Format Raw Data.
2. Verify source column A and its numbers remain unchanged.
3. Verify formatted Raw Data contains matching `#` values.
4. Run with a source missing `#` and verify a clear error occurs without mutation.
5. Rebuild the Raw Data template and confirm its Section H `#` column remains.

## Known issues intentionally unchanged

The Source - Raw Data lifecycle rename/hide and all other active-sheet formatter
behavior remain unchanged.
