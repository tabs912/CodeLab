# Module 2 v2.17.1 / Module 5 v3.24.1 Release Notes

## Functional summary

Sheet creation and template formatting now resolve tab ranks from the exact
Format Dashboard Section B row for the sheet being handled. Dedicated template
rows therefore retain their 801-814 ranks instead of inheriting the active
sheet family's rank.

## Change log

- Prefer exact template names when resolving ranks for existing sheets.
- Use a dedicated template creation rule during governed template creation.
- Preserve the dedicated template rule when rewriting governance metadata.
- Return the dedicated template rank from dashboard template configuration.
- Increment the Format Dashboard template version to 3.24.1.

## Dependency and performance impact

The public workflow entry points and configuration schema are unchanged. Rank
resolution adds only constant-time object lookups and no Spreadsheet service
calls.

## Test plan

1. Build all templates from a dashboard containing the standard Section B rows.
2. Verify template governance notes report ranks 801 through 812 and 814 as
   configured.
3. Create active monthly sheets and verify their ranks remain dynamic from bases
   21 through 30.
4. Run **Organize Tabs** and confirm active sheets remain ahead of templates.

## Known issues intentionally unchanged

No changes were made to dynamic monthly rank arithmetic, naming patterns,
visibility, collision policies, or template formatting.
