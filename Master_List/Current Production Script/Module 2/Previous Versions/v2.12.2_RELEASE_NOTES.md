# Module 2 v2.12.2 Release Notes

## Summary

Module 2 v2.12.2 writes the resolved tab-ranking value into the note on cell `F1` for every sheet created by the governed sheet factory.

## Changes

- Added `writeSheetGovernanceNote_()`.
- Ensures the created sheet has at least six columns before accessing `F1`.
- Writes `Tab Rank`, `Group`, `Visibility`, `Dynamic Rank`, and zero-based `Insertion Index` to the `F1` note.
- Preserves any existing non-governance note text copied from the template.
- Replaces a prior `[Sheet Governance]` block instead of appending duplicate or stale ranking data.
- Calls the note writer immediately after governance placement.

## Preserved behavior

- Module 2 v2.12.1 remains the implementation base.
- Governance collision, rank, placement, visibility, and protected-tab behavior is unchanged.
- Raw Data header-normalization and preservation verification are unchanged.
- CP Due and Unlock CP source dates are unchanged.
- Dashboard Section G number formats remain active.

## Test plan

1. Create an active governed sheet and confirm `F1` has a note containing its active tab rank.
2. Create a template and confirm `F1` contains its template tab rank and `Visibility: HIDDEN`.
3. Create a five-column CP Due output and confirm column F is added and the note is written.
4. Use an `INCREMENT` collision and confirm the final sheet receives the resolved rank note.
5. Use a dynamic rank rule and confirm `Dynamic Rank: YES` and the evaluated rank are written.
6. Copy from a template with an existing `F1` note and confirm the existing text is retained once.
7. Re-run creation and confirm only one `[Sheet Governance]` block exists.
