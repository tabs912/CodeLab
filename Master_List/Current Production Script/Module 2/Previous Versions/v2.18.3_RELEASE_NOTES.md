# Module 2 v2.18.3 Release Notes

## Functional summary

Disenrolled Exclusion now displays `Total Disenrollments` in E1 and its
`Last Updated:` timestamp in E2. Raw Data and Refined Data totals remain in
their existing G1/G2 locations.

## Change log

- Add optional summary and timestamp destinations to the shared unique-PMR
  total writer.
- Write the Disenrolled Exclusion total to E1.
- Write the Disenrolled Exclusion timestamp to E2.
- Retain G1/G2 as the default for Raw Data and Refined Data.
- Preserve the existing unique-PMR calculation and Raw Data safety comparison.

## Dependency and performance impact

Only the destination ranges changed. Counting remains in memory and uses the
same single summary write and single timestamp write.

## Test plan

1. Run Create/Update Disenrolled Exclusion.
2. Verify E1 contains `Total Disenrollments: <count>`.
3. Verify E2 contains `Last Updated: <timestamp>`.
4. Verify G1 and G2 are not written by the disenrollment total workflow.
5. Confirm Raw Data and Refined Data continue using G1 and G2.

## Known issues intentionally unchanged

Disenrollment counting, Raw Data matching, source integrity, and participant
workflow logic are unchanged.
