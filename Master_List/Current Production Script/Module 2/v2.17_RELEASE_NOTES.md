# Module 2 v2.17 Release Notes

- Extends the governed output factory to create active outputs, templates, base/system sheets, and restored local archive sheets.
- Supports an explicitly selected template or source sheet while retaining governance collision, rank, visibility, note, trimming, and index behavior.
- Allows protected system tabs to be replaced only through an explicitly authorized system-setup factory call.
- Adds governed sheet-type resolution for monthly sheet names restored from archive.
- Changes Disenrolled Exclusion insertion to copy the existing data-row format before writing values and never clear existing formatting.
