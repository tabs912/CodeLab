# Module 2 Dashboard-Only Template Formatting — v3.16

## Functional summary

Every non-base template now receives visual formatting exclusively from `Format Dashboard` or `Default - Format Dashboard`. The base template remains governed by Section A `Base Template` markers. No template builder supplies coded visual fallbacks or Index-specific styles.

## Change log

- Added Module 3 v2.0.5 and Module 5 v3.16; preserved v2.0.4 and v3.15 as release snapshots.
- Supports comma- and slash-delimited Section C column-width lists.
- Removed coded operational defaults for date format, wrap, and alignment.
- Uses Section A Header Row and Data Start Row for headers, data formatting, and filter placement.
- Reuses one dashboard configuration through general and operational formatting passes.
- Removed coded Index header fallback, font overrides, fills, and conditional formatting.
- Added all ten Index headers to Section H, including the intentional blank spacer at column 5.
- Preserves Section H column order, including blank header positions.
- Requires all Index and report-template headers from Section H.
- Retains the v3.15 default-dashboard bootstrap and Section C-scoped color calculation.

## Formatting ownership

- Section A: baseline formatting, row placement, defaults, and base-template inclusion.
- Section C: template width lists, theme Base Color, column count, alternating colors, and subheader behavior.
- Section E: title-row formatting.
- Section F: subheader-row formatting.
- Section G: per-column widths, header sizes, formats, wraps, and alignments.
- Section H: ordered template headers.

## Dependency impact

- Module 3 v2.0.5 requires Module 5 v3.16.
- Existing template builder names remain compatible.
- Missing required dashboard formatting now produces a descriptive error instead of a coded visual fallback.
