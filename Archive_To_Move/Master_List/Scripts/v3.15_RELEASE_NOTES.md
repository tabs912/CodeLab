# Module 2 Default Format Dashboard Base-Template Build — v3.15

## Functional summary

`BuildDefaultFormatDashboard()` now creates `Default - Format Dashboard` from `RFF_BASE_TEMPLATE`, writes the complete default dataset, calculates Section C Level 1–5 colors from each structural row's Base Color and Section A HSL percentages, and then passes the existing dashboard to `buildGeneralTemplate_()` without copying or naming it again.

## Corrected failure

Resolved:

```text
Error: Format Dashboard has an invalid Base Color for Format Dashboard.
```

The prior theme lookup found the `Format Dashboard` entry in Section B before the structural entry in Section C, then read Section B's fourth column as though it were Base Color. Theme and hex recalculation are now restricted to Section C boundaries.

## Change log

- Added public `BuildDefaultFormatDashboard()` and retained `buildFormatDashboardTemplate_()` as a compatibility wrapper.
- Creates the default dashboard by copying `RFF_BASE_TEMPLATE` through `createTemplateFromBase_()`.
- Writes the complete default matrix to that existing sheet in one batch.
- Adds one blank row above every section header and four blank rows after every section.
- Calculates Section C Level 1–5 values from Base Color using the five Section A HSL percentages.
- Loads template configuration from the newly created default dashboard explicitly, preventing an older active dashboard from overriding bootstrap configuration.
- Added `existingTemplateSheet` support to `buildGeneralTemplate_()` so it skips base copying and renaming for the already-created default dashboard.
- Prevents generated subheader blocks from overwriting existing dashboard section data.
- Restricts theme lookup and hex recalculation to Section C structural rows.

## Dependency impact

- Module 5 v3.15 requires Module 3 v2.0.4.
- Existing callers of `buildFormatDashboardTemplate_()` remain compatible.
- Deploy only the five scripts listed in `Current_Modules/README.md`.

## Performance impact

- Default data remains a single batched `setValues()` write.
- The base template is copied only once.
- The general template pass reuses the existing copied dashboard rather than creating another sheet.
