# Module 2 Dashboard Build Release Notes — v3.13.1

## Functional summary

`Default - Format Dashboard` is now created in two explicit phases:

1. Create a clean sheet and write only the governed default dashboard values.
2. Pass that populated, unformatted sheet through `buildGeneralTemplate_` for all baseline, title, section-banner, header, sizing, metadata, tab-color, and visibility formatting.

The active `Format Dashboard` continues to be created from `Default - Format Dashboard` by the existing active-system-sheet workflow.

## Change log

- Added support for supplying a populated, unformatted sheet to `buildGeneralTemplate_`.
- Added general baseline formatting for supplied data-only sheets.
- Added general formatting of existing section banners and their header rows.
- Changed the dashboard builder to create and populate `Default - Format Dashboard` before invoking the general template builder.
- Removed the dashboard builder's duplicate post-build title/subheader formatting calls.
- Incremented the dashboard template version from `3.13` to `3.13.1`.

## Dependency impact

- Requires Module 3 v2.0.1 when using Module 5 v3.13.1.
- Preserves the existing `buildGeneralTemplate_(config, timing)` public/internal signature.
- Preserves existing menu callbacks and active-dashboard creation behavior.

## Performance impact

The dashboard data is written once in a batch before formatting. Section banner and header ranges are formatted with `RangeList` batches. No cell-by-cell spreadsheet writes were introduced.

## Test plan

1. Run the system-template creation workflow.
2. Confirm `Default - Format Dashboard` contains all Sections A–H and governed default values.
3. Confirm the default dashboard has the general font, alignment, wrapping, frozen rows/columns, column widths, title formatting, section banners, and section header formatting.
4. Run active-system-sheet creation and confirm `Format Dashboard` is copied from the default dashboard.
5. Change a dashboard theme setting, rebuild, and confirm the general template pass applies the configured theme.
6. Build Framework Timing, Dashboard Quality, Index, and operational templates to confirm unchanged general-builder behavior.

## Known issues intentionally unchanged

- Initial dashboard content remains seeded from `MASTER_FORMAT_DEFAULTS`; an existing dashboard can govern formatting configuration but does not replace the coded recovery defaults.
- Google Apps Script runtime behavior requires validation in a bound spreadsheet because local syntax checks cannot execute Spreadsheet service calls.
