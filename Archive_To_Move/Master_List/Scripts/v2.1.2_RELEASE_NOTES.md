# Module 4 Header-Mapped Quality Results — v2.1.2

## Functional summary

Dashboard Quality results are now mapped to each section's displayed column headers rather than written to fixed column numbers. Reordering Quality Dashboard columns no longer misplaces validation subjects, statuses, notes, or failure highlighting.

## Change log

- Passed semantic source headers into the shared subheader writer for every Quality Dashboard section.
- Resolved the displayed Status/Result column before applying failure highlighting.
- Added normalized aliases for the section-specific subject, status/result, and notes header labels.
- Preserved all quality workflows, validation logic, and public entry points.

## Dependencies and compatibility

- Requires Module 1 v1.94.2 for shared header-mapping helpers.
- Deploy with the other versions listed in `CURRENT_MODULES_README.md`.
- Existing Format Dashboard and Default - Format Dashboard templates remain compatible.

## Test plan

1. Rearrange columns independently in Quality Dashboard Sections A–H.
2. Run the complete Dashboard Quality workflow.
3. Confirm every value and FAIL highlight appears under its named header.
4. Run JavaScript syntax validation across all five current modules.

## Known issues

- Section titles and displayed header names must remain present; arbitrary renaming is not supported beyond the documented normalized aliases.
