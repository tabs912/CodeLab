# Module 2 Dashboard-Governed Number Formats — v2.9

## Functional summary

The monthly-sheet formatter now uses Format Dashboard Section G as the sole source for identifying number-formatted columns and for selecting the number format applied to each populated data column.

## Change log

- Replaced the date-specific post-write formatter with `applyGovernedNumberFormatsFromDashboard_()`.
- Matched each monthly output header to its Section G column definition.
- Applied the Section G `Number Format` value to the populated data range when that value is configured.
- Removed hardcoded `MM.yy` overrides for `Demo P Update Month` and `Added to Disenrolled Exclusion`.
- Left columns with a blank Section G `Number Format` unchanged.
- Updated formatter timing to report that number formats are read from Section G.

## Dependencies and compatibility

- Deploy with Module 5 v3.19 and the other scripts listed in `CURRENT_MODULES_README.md`.
- Existing monthly-sheet menu callbacks and pipeline entry points are unchanged.
- Any column requiring a number format must have a nonblank `Number Format` in Format Dashboard Section G.

## Performance impact

Number formatting remains column-batched: one `setNumberFormat()` call is made per governed output column, never per cell or per row.

## Test plan

1. Set distinct Section G number formats for multiple monthly output headers.
2. Run **Format Monthly Sheets** and verify each populated data column uses its configured format.
3. Verify a column with a blank Section G number format retains its template formatting.
4. Change the Section G format for `Demo P Update Month` and verify no hardcoded override replaces it.
5. Confirm formatting stops at the final populated data row.

## Known issues

- Number formats configured for headers not present in a particular monthly output are intentionally ignored.
