# Module 2 v2.10 Release Notes

## Base version

Module 2 v2.10 is based on `MODULE 2 v2.9: DATA PROCESSING & OUTPUT ENGINE (DASHBOARD-GOVERNED NUMBER FORMATS)`.

It retains v2.9's `applyGovernedNumberFormatsFromDashboard_()` processing and adds the requested monthly-formatting corrections.

## Changes

- CP Due output cells `B2` and `D2` are explicitly stamped with the prompted month start and end dates.
- Unlock CP output cells `B2` and `D2` are explicitly stamped with the prompted month start and end dates.
- Raw Data output headers contain the governed Section H headers followed by every unique source-only import header.
- Raw Data source-only values are retained through header mapping.
- The governed sheet factory expands the output grid and writes the complete runtime header set before writing data.

## Preserved v2.9 behavior

- Dashboard Section G number formats are applied through `applyGovernedNumberFormatsFromDashboard_()`.
- Existing governed columns retain their Section H order.
- Banners, CP Due, and Unlock CP archive behavior is unchanged.
- Public menu callbacks and workflow signatures are unchanged.

## Dependency and performance impact

- No new external dependency is introduced.
- Raw Data outputs can be wider than the configured template when imports include extra columns.
- Source-only headers are deduplicated in memory before one header-row write and one data-matrix write.

## Test plan

1. Run Format Monthly Sheets for a prompted month whose CP Due `C3`/`E3` values differ; verify output `B2`/`D2` use the prompted month.
2. Repeat with Unlock CP source dates in `E2`/`G2`.
3. Add uniquely named RD columns absent from Section H; verify their headers and values follow the governed columns.
4. Verify Section G number formats still apply to governed output columns.
5. Verify original governed Raw Data column order and values.
6. Run Create Monthly Start and confirm Refined Data maps governed Raw Data columns normally.

## Known issues unchanged

- This release does not change the modular Raw Data source/output sheet lifecycle.
- Other documented parity findings for Monthly Start, Monthly Update, Monthly Change, Disenrolled Exclusion, and Master List remain outside this release.
