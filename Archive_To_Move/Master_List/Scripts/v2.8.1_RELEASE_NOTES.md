# Module 2 v2.8.1 Release Notes

## Summary

Module 2 v2.8.1 makes the prompted report month authoritative for CP Due and Unlock CP output dates and preserves Raw Data import columns that are not declared in Format Dashboard Section H.

## Changes

- CP Due output cells `B2` and `D2` are explicitly stamped with the prompted month start and end dates.
- Unlock CP output cells `B2` and `D2` are explicitly stamped with the prompted month start and end dates.
- Raw Data output headers now contain the governed Section H headers followed by every unique source-only import header.
- Raw Data source-only column values are retained through the existing header-mapping pipeline.
- The governed sheet factory expands the output grid and writes the complete runtime header set before writing data.

## Compatibility and impact

- Existing governed columns retain their Section H order.
- Extra imported Raw Data columns are appended after governed columns in original source order.
- Banners, CP Due, and Unlock CP archive behavior is unchanged.
- Public menu callbacks and workflow signatures are unchanged.
- Raw Data outputs can be wider than the configured template when an import contains extra columns.

## Test plan

1. Run Format Monthly Sheets for a prompted month whose CP Due `C3`/`E3` values differ from that month; verify output `B2`/`D2` use the prompted month.
2. Repeat for Unlock CP with differing `E2`/`G2` source dates.
3. Add two uniquely named columns to an RD import that are absent from Section H; verify both headers and values appear after governed Raw Data columns.
4. Verify the original order and values of all governed Raw Data columns.
5. Run Create Monthly Start and confirm Demo P/Refined Data still maps governed Raw Data columns normally.

## Known issues unchanged

- This release does not change the modular Raw Data source/output sheet lifecycle.
- Other processing-parity findings documented for Monthly Start, Monthly Update, Monthly Change, Disenrolled Exclusion, and Master List are outside this release.
