# Module 5 Updated Format Dashboard Defaults — v3.19

## Functional summary

The generated Default - Format Dashboard now reflects the approved settings in `Master_List/Specs/Module 2  - updated Format Dashboard.csv`. Global base-template participation, theme levels, title formatting, subheader formatting, and border style have been aligned with the supplied dashboard.

## Change log

- Disabled base-template participation for Header Row, Data Start Row, Row 4 Height, Default Background Color, Default Date Format, and Default Number Format.
- Changed the global border style from `SOLID` to `DOTTED`.
- Added the supplied Level 4 colors and shifted the previous light colors to Level 5 for every Section C sheet definition.
- Extended title row 1 formatting through column F and title row 2 wrap formatting through column F.
- Changed the governed title header-row height from 40 to 30 pixels.
- Changed the column C section-header label from normal to italic.
- Updated the generated dashboard template version to 3.19.

## Dependencies and compatibility

- Deploy with the other four scripts listed in `CURRENT_MODULES_README.md`.
- Existing dashboard builders and configuration readers remain unchanged.
- Existing active dashboards must be rebuilt to receive these revised defaults.

## Performance impact

No additional Spreadsheet service calls or parsing passes were introduced. Only the default configuration data changed.
