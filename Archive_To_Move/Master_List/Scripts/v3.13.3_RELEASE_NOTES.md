# Module 2 Bootstrap-Safe Dashboard Formatting Release Notes — v3.13.3

## Functional summary

The dashboard builder no longer requests theme-dependent template configuration before either `Default - Format Dashboard` or `Format Dashboard` exists. It first loads recovery data, creates the unformatted default dashboard, writes the complete default matrix, and only then loads dashboard-governed template formatting.

## Corrected failure

Resolved:

```text
Error: Default - Format Dashboard or Format Dashboard is required for template formatting.
```

The failure occurred because `getTemplateConfigFromDashboard_("Format Dashboard")` resolved the theme before the bootstrap workflow created `Default - Format Dashboard`.

## Change log

- Removed the pre-bootstrap call to `getTemplateConfigFromDashboard_`.
- Obtained the bootstrap dashboard width from the recovery configuration's `Format Dashboard` structural record.
- Created and populated `Default - Format Dashboard` before requesting any theme-dependent configuration.
- Loaded `getTemplateConfigFromDashboard_("Format Dashboard")` only after the dashboard sheet exists.
- Obtained the default-dashboard template rank from its recovery creation rule rather than a builder literal.
- Preserved strict dashboard ownership of all formatting after bootstrap.

## Dependency impact

- Module 5 v3.13.3 requires Module 3 v2.0.2.
- No public function or menu callback names changed.

## Test plan

1. Delete both `Default - Format Dashboard` and `Format Dashboard` in a test workbook.
2. Run the dashboard template build.
3. Confirm the unformatted default dashboard is created and populated before template configuration is loaded.
4. Confirm general formatting succeeds using the newly created default dashboard.
5. Create the active `Format Dashboard` and confirm it inherits the formatted default.
6. Repeat with an existing active dashboard and confirm its formatting configuration remains authoritative.
7. Remove the Format Dashboard structural Column Count or template-rank recovery record and confirm a descriptive recovery-data error is raised.

## Known issues intentionally unchanged

Google Apps Script Spreadsheet service execution still requires validation in the bound workbook.
