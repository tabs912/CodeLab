# Module 3 Dashboard-Governed Subheader Rows — v2.0.7

## Functional summary

Title rows and every row in each six-row subheader block now receive their Height, Fill Level, Font Size, Font Weight, Alignment, and Wrap values from Format Dashboard. Existing section layouts now format row 3 and the other structural rows instead of formatting only the section banner and column-header row.

## Change log

- Applied all six Section F subheader row specifications when formatting existing section-based sheets.
- Corrected subheader row 3 formatting so its governed height, fill, font, alignment, and wrap settings are applied.
- Centralized row-spec selection for generated and existing subheaders.
- Allowed sheet-specific dashboard specifications to override earlier GLOBAL specifications for the same row.
- Preserved the existing dashboard-driven title-row formatting behavior.

## Dependencies and compatibility

- Deploy with the other four scripts listed in `CURRENT_MODULES_README.md`.
- Existing public template-builder entry points are unchanged.
- Format Dashboard Section E remains the source for title-row formatting; Section F remains the source for subheader-row formatting.

## Performance impact

Existing section formatting adds a bounded six-row formatting pass per section. No cell-by-cell data reads or writes were introduced.

## Test plan

1. Set distinct Height, Fill Level, Font Size, Font Weight, Alignment, and Wrap values for each Section F row.
2. Rebuild a subheader-based template and verify all six rows, especially row 3, match Format Dashboard.
3. Format a populated existing section-based sheet and verify all six relative rows match Section F.
4. Add a sheet-specific Section F row after the GLOBAL row and verify the sheet-specific values win.
5. Change Section E values and verify title rows continue to match Format Dashboard.

## Known issues

- Existing sections must retain the standard six-row structure with the section title in subheader row 2.
